# RavMem

**A server-first code knowledge graph engine with an integrated agent memory layer.**

RavMem indexes source repositories into a queryable graph of symbols, edges,
and clusters — and pairs it with a memory store for agent instructions,
learnings, decisions, and tasks. One server, exposed via REST, MCP, and
WebSocket, so every client talks to the same source of truth.
